## 2. 다음 배치 설계 결정 (30분) — 오늘의 핵심

결정할 항목:

1. **수량**: 다음 배치 60~100개. 600 전체는 이 배치의 검수 결과를 본 뒤.
2. **셀 우선순위**: 쉬운 제3자 표본은 그만. 아래 셀부터 채운다.
   - 담화 의존(Local에서 확정 불가) + 경쟁 개체 있음
   - 화자가 유지되는 표본(현재 1개)
   - 정답이 화자·청자인 표본(현재 각 4개)
   - 3인 대화에서 청자가 호격 없이 확정되는 표본
3. **작성 방식**: 사람 직접 작성 vs 생성 모델 초안 + 사람 수정. 생성자 편향 비교를 위해 사람 작성 표본을 일정 비율(제안: 절반) 확보한다. 작성 방식은 `creation_method`에 기록.
4. **작성자·검수자 분리**: 작성자는 자기 표본을 검수하지 않는다. 3명이면 작성 1명 + 검수 2명을 배치별로 돌린다.
5. **검수 절차 확정**: Local 먼저 → Full → pair 시트 → 조정. 검수 페이지 사용 여부와 CSV 제출 방식.
6. **난도 기준**: 강한 모델이 틀리도록 억지로 만들지 않는다. 사람 2명이 Full에서 확정할 수 있는 선을 유지한다(일치도로 확인).
