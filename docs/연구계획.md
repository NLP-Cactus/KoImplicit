# 자연어처리 팀 프로젝트 — 연구 계획

> **설계 이력 문서(2026-10-10 이후 실행 기준 아님).** 이 프로젝트는 국립국어원 말뭉치를 사용하지 않기로 했고 데이터 전략을 독립 창작 데이터셋으로 바꿨다. 이 문서의 말뭉치 사용 전제, 모델 결과에 따른 난도 조정, distractor 선택을 곧바로 이해 실패로 보는 해석은 현행 규칙과 다르다. 현행 절차는 [docs/데이터셋_구축방법.md](데이터셋_구축방법.md)와 [AGENTS.md](../AGENTS.md)를 따른다. 연구 기록으로 보존한다.

## 1. 연구 주제

- **국문:** 한국어 다중턴 대화에서 화자·청자·담화 대상 전환에 따른 LLM의 생략 논항 추적 능력 분석
- **영문:** Evaluating Null-Argument Tracking in Korean Multi-Turn Dialogue under Speaker, Addressee, and Discourse-Entity Shifts

`Topic Shift`가 아니라 `Discourse-Entity Shift`라고 쓴다. 대화 주제(축구→음식)가 바뀌는 것이 아니라, 생략된 논항이 가리키는 대상이 바뀌는 현상을 다루기 때문이다.

## 2. 문제 정의

한국어는 문맥상 추론 가능한 주어·목적어를 흔히 생략한다.

| 대화 | 생략 주어 |
|---|---|
| A: 민수 내일 학교 온대? / B: 응, 온다고 했어. | 민수 (third-party) |
| A: 너 내일 학교 와? / B: 응, 갈 거야. | B (speaker) |
| A: 민수 내일 학교 온대? / B: 응. 나한테 같이 밥 먹자고 했어. / A: 몇 시에 온대? | 마지막 `온대?` → 민수 |

모델은 최근 등장 명사를 찾는 것이 아니라 speaker → addressee → third-party entity 사이에서 변하는 담화 상태를 추적해야 한다.

**핵심 질문:** LLM이 담화 참여자 구조를 실제로 추적하는가, 아니면 최근 명사·화자·표면 표현 같은 heuristic으로 푸는가?

## 3. Research Questions

| RQ | 내용 | 역할 |
|---|---|---|
| RQ1 | How accurately can LLMs resolve omitted arguments in Korean multi-turn dialogue? | baseline |
| RQ2 | How do discourse-participant shifts (Speaker / Addressee / Third-party) affect null-argument resolution? | 핵심 |
| RQ3 | Which contextual cues (speaker label, recent entity, sentence ending, honorific-person cue) do LLMs rely on? | 진단 |

Ambiguity detection은 RQ로 두지 않고 supplementary analysis로 둔다. 일반 coreference에서의 resolution/detection trade-off는 Correct-Detect(EMNLP 2025)가 이미 다뤘다.

## 4. 가설

- **H1.** referent가 유지될 때보다 speaker/addressee/third-party 사이에서 전환될 때 성능이 낮다.
- **H2.** antecedent와 생략 논항 사이에 경쟁 entity가 추가될수록 성능이 낮다.
- **H3.** speaker label, sentence ending 등 discourse cue를 제거·교란하면 성능이 낮다.
- **H4.** 일부 모델은 discourse state보다 recent-entity heuristic에 의존한다.

## 5. Dataset

### Dataset A — Controlled Benchmark (직접 제작)

기본 scenario에서 minimal pair를 생성한다.

| 변수 | 조건 |
|---|---|
| Referent Type | Speaker / Addressee / Third-party |
| Shift | 유지 / 전환 |
| Distance | 1 / 3 / 5 turns |
| Distractor | 없음 / 있음 |
| Omission | Subject / Object |

- MVP: 3 referent × 2 shift × 3 distance × 2 distractor = **36 conditions**
- condition당 20문항 → **720문항**, 모델 3개 → **2,160 inference**

### Dataset B — Natural Korean (외부 검증)

- 출처: 국립국어원 「무형 대용어 복원 말뭉치 2024」(모두의 말뭉치). 주어·목적어·보어·필수 부사어 등 생략 성분을 문맥에 따라 복원한 데이터.
- 대화 사례 200~300개를 뽑아 `Speaker / Addressee / Third-party / Ambiguous`로 추가 annotation.
- 역할 구분: Controlled = 왜 실패하는가, Natural = 실제 데이터에서도 실패하는가.

## 6. Minimal Pair 실험

한 번에 cue 하나만 바꾼다.

- **Speaker cue:** `A: 너 내일 갈 거야? / B: 응, 갈게.` ↔ 화자 라벨 제거본
- **Recency trap:** 정답 entity보다 distractor entity를 더 최근에 배치하고, 모델이 distractor를 고르면 recent-entity bias로 기록.

## 7. Cue Ablation (RQ3)

Original → Speaker label removed → Ending normalized → Honorific cue removed → Recent distractor inserted

조건마다 하나만 바꿔서 정확도 변화의 원인을 분리한다.

## 8. Annotation

- 팀원 최소 2명이 독립적으로 `Speaker / Addressee / Third-party / Ambiguous` 라벨링
- Cohen's κ로 agreement 계산, 불일치 문항은 논의 후 gold 확정
- `Ambiguous`는 사람도 모호한 문항을 모델 오답으로 처리하지 않기 위해 반드시 둔다.

## 9. 모델

- 서로 다른 family 3개: Qwen 계열 / Gemma 계열 / EXAONE 등 한국어 성능이 괜찮은 계열
- 가능하면 commercial frontier model 1개를 reference로 추가
- 동일 prompt·decoding 조건, temperature 0

## 10. Prompt (객관식, Exact Match 채점)

```text
다음 대화에서 [Ø]에 생략된 대상이 누구인지 판단하세요.

A: 민수가 내일 학교 온대?
B: 응. [Ø] 온다고 했어.

선택지:
A. 화자 A
B. 화자 B
C. 민수
D. 판단할 수 없음

정답의 알파벳 하나만 출력하세요.
```

Gold: `C`. LLM-as-a-Judge는 쓰지 않는다.

## 11. 평가 지표

| 지표 | 정의 |
|---|---|
| Accuracy | 전체 정답률 |
| Accuracy by Referent Type | Speaker / Addressee / Third-party별 |
| Shift Degradation | Acc(no shift) − Acc(shift) |
| Distance Degradation | Acc(d=1) − Acc(d=5) |
| Distractor Error Rate | distractor 조건에서 distractor 자체를 고른 비율 |

## 12. 통계

- 기본: mixed-effects logistic regression
  `Correct ~ ReferentType + Shift + Distance + Distractor + Model + interactions + (1|item)`
- 수업용으로 부담되면 χ² / bootstrap CI, 논문화할 때 mixed-effects로 확장

## 13. 결과 그림

1. Accuracy by Referent Type
2. Accuracy vs Turn Distance (1 → 3 → 5)
3. No Shift vs Shift (main result)
4. Cue Ablation
5. Error Distribution (Recent entity / Wrong speaker / Wrong addressee / Ambiguous)

## 14. 결과 시나리오

| 결과 | 해석·대응 |
|---|---|
| Shift에서 유의미한 하락 + distractor 선택 증가 | 한국어 담화 참여자 추적 약점 발견 (최선) |
| 모델별 cue 의존성이 크게 다름 | 모델마다 처리 전략이 다르다는 결과 |
| 전 모델 95~100% | 난도 상향: 2-party → 3-party, 1 shift → multiple shifts, subject → object, natural dialogue |
| 그래도 전부 잘함 | 결과이긴 하나 논문성 약함 → pilot으로 사전 차단 |

## 15. Pilot (이번 주 목표)

1. annotation schema 확정
2. controlled template 10종 제작
3. 변형으로 60~100문항 생성 (Speaker/Addressee/Third-party × Shift 유무 × Recent distractor 유무)
4. 모델 2~3개 pilot → ceiling effect 확인

- 98~100%: 설계를 바로 어렵게 수정
- 94 → 81 → 67% 같은 하락 패턴: 그대로 확장
- failure pattern이 하나라도 보이면 GO. 차이가 없으면 주제를 바꾸지 않고 같은 RQ 안에서 harder condition을 설계한다.

## 16. Contribution

- **C1. Controlled benchmark:** 한국어 다중턴 대화의 implicit discourse participant tracking 평가용
- **C2. Systematic diagnosis:** shift·distance·distractor를 통제한 failure 분석
- **C3. Cue dependency:** minimal pair·cue ablation으로 담화·화용 단서 활용 vs recency heuristic 의존을 분석 (가장 중요)

## 17. 기존 연구와의 위치

- 한국어 zero-anaphora 데이터셋 "최초"라고 주장하지 않는다 (국립국어원 말뭉치 존재).
- ambiguity 자체를 novelty로 주장하지 않는다 (Correct-Detect).
- 우리 위치: Korean null arguments × multi-turn discourse participant tracking × controlled participant shifts × minimal-pair cue intervention × LLM failure analysis

## 부록. 설계 검토 메모 (2026-10-02, Claude 검토)

원안 내용을 바꾸지 않고 확인이 필요한 지점만 따로 적는다. 팀에서 논의 후 반영 여부를 정한다.

1. **Recency trap 예시의 gold가 흔들린다.** `A: 민수가 지훈이 만났대? / B: 응. 지훈이는 오늘 부산 간대. / A: 그래서 어제 왜 만났대?`에서 "만나다"는 대칭 동사라 생략 주어를 지훈으로 읽어도 틀렸다고 하기 어렵다. 모델이 지훈을 골라도 recency bias라고 단정할 수 없다. 대칭 동사가 아닌 술어(예: 연락하다, 부탁하다)로 바꾸고 annotator 2인 검증을 거쳐야 한다.
2. **Shift의 조작적 정의가 필요하다.** "직전 생략 논항의 referent 대비 바뀜"인지 "직전 발화의 주어 대비 바뀜"인지 정해야 한다. Speaker/Addressee는 발화 턴마다 A·B가 서로 바뀌는 상대적 역할이라, Referent Type과 Shift를 교차할 때 조건이 겹치거나 성립하지 않는 칸이 생길 수 있다. generator 만들기 전에 36칸을 하나씩 예시로 채워 보는 것을 권한다.
3. **선택지 순서 편향.** 객관식이면 position bias가 생긴다. 선택지 순서를 섞거나 정답 위치를 균형 있게 배치해야 한다. 또 선택지 라벨(A/B/C/D)이 화자 라벨 A·B와 겹치므로 `1/2/3/4`로 바꾸는 편이 안전하다.
4. **Cue ablation의 confound.** 어미 정규화나 높임 단서 제거가 문장을 비문 또는 부자연스럽게 만들면, 성능 하락이 cue 상실 때문인지 자연스럽지 않은 입력 때문인지 구분하기 어렵다. 변형 문장의 자연스러움을 사람이 확인하는 단계가 필요하다.
5. **말뭉치 접근·라이선스.** 무형 대용어 복원 말뭉치는 언어정보나눔터에서 신청·승인 후 받는 구조다. 승인 기간과 재배포 금지 조건(데이터셋 공개 시 원문 포함 가능 여부)을 일찍 확인해야 한다. 2025년 버전도 공개됐다는 검색 결과가 있는데, 아직 직접 확인하지는 않았다.
6. **일정.** 원안이 9월 중순 기준이라 위 일정표를 그대로 쓰면 종강 전에 끝나지 않을 수 있다.
